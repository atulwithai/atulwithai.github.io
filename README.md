## Studio Work & Lab Projects

- **Nova Studio Interface**: Minimalist dashboard architecture exploring dense telemetry feeds and human-in-the-loop review gates.
- **AI Visual & Prompt Lab**: Systematic explorations in multimodal generative media and rapid asset prototyping.
